See appointments on your phone

Subscribe to this private link once in Google Calendar, Apple Calendar or Outlook. New bookings appear automatically (Google refreshes subscribed calendars every few hours). Keep the link private.

This server is only reachable on this computer (localhost), so phones can't load the link yet. It starts working once VaaniDesk is online (see docs/GO_LIVE.md, Step 2).

How to add it
  • Google Calendar (computer): calendar.google.com → Other calendars + → From URL → paste → Add calendar. It then appears on your phone's Google Calendar app.
  • iPhone: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste.
  • Outlook: Add calendar → Subscribe from web → paste.
